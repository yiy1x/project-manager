# 猫老大只读接口约定

这是现有本机接口的适配说明，不是对猫老大所有版本的兼容承诺，也不提供网关安装包。

## 请求与响应

首次 GET `/v1/catboss/trace`。成功后 GET `/v1/catboss/trace?after=<seq>&wait=1` 等待增量。

以下为虚构结构示例；`now` 必须是服务器当下的带时区时间，不能原样复制固定日期作为实时响应。

```json
{
  "object": "trace",
  "now": "2026-11-16T10:00:00+08:00",
  "seq": 12,
  "pid": 1234,
  "ids": [101],
  "routes": [
    {
      "id": 101,
      "agent": "codex",
      "session": "example-session",
      "time": "2026-11-16T09:59:59+08:00",
      "model": "example-model",
      "folder": "example-project",
      "done": false,
      "status": 200
    }
  ]
}
```

- `seq`、`pid`：整数，分别用于增量游标和网关进程代际。
- `ids`：当前仍保留的路由 ID 全集；未列出的旧路由从缓存删除。
- `routes`：首次快照或本次改变的路由。仅接受 `agent` 为 `codex` / `claude` 且没有内部 `kind` 的条目。
- `session`：与本机聊天 ID 精确关联；不按标题猜测。不含会话 ID 的 Claude 请求只能展示为未关联请求。
- `done`：必须是布尔值。`false` 即模型请求中，即便 `status` 为 200。
- `status`：整数 HTTP 状态；错误只代表该请求，不能直接推出项目失败。
- `model`、`folder`：可选展示元信息。不会保留提示词、响应正文、尝试记录、凭据等额外字段。

## 可靠性

- 首次超时 1.5 秒，增量等待超时 35 秒；响应最多 2 MiB。
- 快照 `now` 允许最多落后 10 秒或超前 5 秒。共享缓存超过 40 秒失效。
- `pid` 改变或 `seq` 回退时，丢弃缓存并重新全量同步。
- 断线清理旧路由，有限退避重连，不把旧「进行中」永久保留。
- 同一会话多个请求中，只要还有请求未结束就保持模型请求中。
- 页面订阅 `/api/activity/events`。一个后端共享订阅服务多个页面，不发模型探测请求。

## 安全边界

只访问 `CATBOSS_TRACE_URL` 指定的回环 HTTP 地址。拒绝 URL 凭据、查询参数与片段，禁用系统代理，不跟随重定向。接口若要求认证，仅显示不可用，不读取猫老大密钥，也不修改网关设置。

模型请求结束不等于工具结束、对话完成或用户验收。自动回读还需要本机保存的整轮完成证据；结项仍只由用户决定。
